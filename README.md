# Python Guessing Game

A desktop number guessing game built with Python and Tkinter

## Features

- Random number generation
- User input validation
- Attempt tracking
- Guess feedback
- Sound effects
- Game reset functionality
- Graphical user interface (GUI)

## Technologies 

- Python
- Tkinter
- MacOS 'afplay'
- PyInstaller

## How to Run

Make sure Python 3 is installed, then run:

```bash
python3 gui_game.py
```

## MacOS Application

This project was also packaged as a standalone macOS application using PyInstaller.

To build the application, run:

```bash
PyInstaller --windowed --name "Guess Game" gui_game.py 
```

The generated application will be placed in the 'dist' folder
